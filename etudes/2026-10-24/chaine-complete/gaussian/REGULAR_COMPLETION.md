# Regular Gaussian completion, second experiment

The complete candidate now computes every inverse spectral slot from the
original p,z inputs. It passes the frozen development evaluator, with score
3670 scalar gates at n=8. Its exact component count is 2^(n-3), so this is
an exponential construction and does not establish the required polynomial
closure. The positive advance is an exact regular Gaussian family for any
layer with all but two rows equal, followed by a shared polarization of the
other rows. This reduces the previous five-component fourth layer to two
components and gives an explicit alternative to factorial component growth.

The separate full skew-matrix completion experiments did not find a general
regular section. Their numerical failures are not impossibility proofs.

## An exact regular family at every layer

Fix a layer k>=3 and any number n>=k of columns. Let the first k-2 rows all
equal a, and let the final rows be b,c. Set r_j=b_j/a_j, s_j=c_j/a_j.
Use the normalized paired-order skew kernel with grouped blocks

```
X_jl = r_l-r_j,
Y_jl = ((k-2)!/k)*(s_l-s_j),
C_jl = delta_jl-1/k+(k-1)!*r_j*s_l.
```

Congruence-scale x_j by a_j and leave y_j unchanged. The resulting K has

```
Pf(K_pair(S)) = per([a repeated k-2 times; b; c]_[S]), |S|=k.    (10)
```

For proof, put U_j=(1,r_j), V_j=(-1/k,(k-1)!s_j). The normalized blocks
are `X=U J2 U^T`, `Y=-(1/(k-1)) V J2 V^T`, and `C=I+U V^T`.
The rank-four update gives

```
Pf(K_normalized)=1+tr(T)+(k/(k-1))*det(T), T=V^T U.
```

On a subset of cardinality l, this is

```
1-l/k + (k-1)!*(1-l/(k-1))*sum rs + (k-2)!*(sum r)*(sum s).
```

At l=k it is `(k-2)!*((sum r)*(sum s)-sum rs)`. Multiplication by
`prod a_j` proves (10), including the factor (k-2)! for assigning the equal
rows. In particular at k=4 and a=b=c=1, X=Y=0 and
`C=I+(23/4)11^T`, exactly the base point requested for the completion test.
This gives a regular section through that base point on the substantial
subfamily with two equal rows, not merely an isolated numerical solution.

## Two components at layer four; 2^(k-3) in general

For four arbitrary rows a,d,b,c, polynomial polarization gives

```
per(a,d,b,c)
 = [per(a+2d,a+2d,b,c)-per(2d-a,2d-a,b,c)]/8.                 (11)
```

Each permanent on the right is the paired Pfaffian (10). Both repeated
rows are nonzero at the all-ones base: a+2d=3 and 2d-a=1. Thus (11) uses
two regular Gaussian components. It applies simultaneously to every
four-column subset, rather than putting a previously computed target
permanent in a kernel entry.

For layer k let m=k-2, with distinct rows a_1,...,a_m followed by b,c.
Choose lambda_i=2^(i-1), fix epsilon_m=1, and range the other signs over
{+1,-1}. Define

```
h_epsilon = sum_(i=1)^m epsilon_i*lambda_i*a_i,
w_epsilon = (prod_i epsilon_i)/(2^(m-1)*m!*prod_i lambda_i).
```

Then the simultaneous identity on all k-column subsets is

```
per(a_1,...,a_m,b,c)
 = sum_epsilon w_epsilon*Pf(K(h_epsilon repeated m times,b,c)). (12)
```

To prove it, apply the sign average to
`(sum epsilon_i lambda_i L_i)^m`, where L_i are commuting linear forms
in the q_j. A surviving monomial must have odd exponent in each of the
first m-1 variables. Since total degree is m, the remaining exponent is
also odd and every exponent must be one. The surviving coefficient is
`2^(m-1)*m!*prod lambda_i`. Multiplication by L_b L_c and comparison of
paired coefficients proves (12). This proof does not expand permutations.

There are 2^(m-1)=2^(k-3) components. At B=J,

```
h_epsilon(0)=2^(m-1)+sum_(i<m) epsilon_i*2^(i-1)
```

is a positive odd integer between 1 and 2^m-1. No component has a pole at
the deformation base. The weight numerators/denominators have O(k^2)
bits; factorial constants in the kernel have O(k log k) bits. All constants
are generated by a uniform finite algorithm.

For a materialized state, deform the independent entries as B(t)=J+t(B-J)
and keep coefficients through degree k. Write h_j(t)=s+t delta_j, where
the known nonzero integer s=h_epsilon(0). Its reciprocal is explicitly

```
sum_(d=0)^k (-delta_j)^d/s^(d+1) * t^d.
```

Consequently each rational Gaussian parameter becomes k+1 ordinary scalar
coordinates, with no input-dependent inverse. Every constant denominator
is controlled. Kernel construction is O(n^2 k^2) scalar gates per component
using dense jet convolution. A dense scalar Pfaffian reader is O(n^4 k^2),
as proved in JOINT_GAUSSIAN.md. This is already a complete charged but
exponential upper bound. The implementation uses the faster exact reader
below and does not materialize parameters that disappear from observation.

## A specialized scalar reader and shared construction

For a full terminal component with n columns and m=n-2 equal rows, (10)
reduces to

```
Pf(K_h)/m! = [uv] product_j (h_j+b_j*u+c_j*v), u^2=v^2=0.       (13)
```

The coefficient operator in (13) is implemented by four explicit scalar
accumulators e0,eb,ec,ebc, initialized to 1,0,0,0. On the next column,

```
e0'  = h*e0,
eb'  = h*eb+b*e0,
ec'  = h*ec+c*e0,
ebc' = h*ebc+b*ec+c*eb.
```

This costs exactly eight multiplications and four additions per column in
the current code, including operations on zero constants. The factor m!
in the Pfaffian cancels the same factor in (12). The remaining weight is
`(prod epsilon)/(2^(m-1)*prod lambda_i)`, a signed reciprocal power of two.
There is no hidden permanent input, variable division, uncharged extraction,
or growing coefficient vector in this reader. Four accumulators suffice
because only the last two row factors are handled by it; the exponential
cost of the other factors is explicitly in the number of components.

Precompute scaled row entries lambda_i*a_ij. Enumerate the first m-1 signs
in Gray-code order. Changing one sign updates every h_j by adding a
precomputed signed value `+2*lambda_i*a_ij` or `-2*lambda_i*a_ij`.
The construction shares these row sums without changing the component count.

For n>=3 the exact gate count of `gaussian_polarization.build` is

```
G(n)=2n^2+4n(n-3)-n-2+(13n+2)*2^(n-3).                        (14)
```

Its contributions are 2n^2-1 for marked inputs, 4n(m-1) for scaled rows,
initial sums and both signs of update vectors, n(R-1) for Gray updates,
12nR for component readers, and 2R-1 for weights and summation, with
R=2^(m-1). Direct bases have G(1)=1 and G(2)=10. The compiler uses
O(n 2^n+n^2) arithmetic operations and emits that many DAG nodes; working
row-sum storage excluding the DAG is O(n^2) node indices. Literal bit
lengths are O(n^2). Accounting for integer indices, rational literals and
their generation gives, conservatively, O(n^3 2^n+n^4) bit work and storage,
plus polynomial work in the bit length of the labels. The construction is
uniform, but its component count is still exponential.

Frequency phases remain joint with this construction: h,b,c in column j
all receive the same omega^(f d_j). Each term of the component readout
uses exactly one factor from every column, and hence receives the common
phase omega^(f sum d_j). Fourier orthogonality therefore routes the
component directly into slot sum(labels) mod N. `build` returns all N
nodes and does not introduce an upstream corrected-amplitude leaf.

The frozen command `python evaluate_dev.py` passed 84 numeric complete
tables and 8 formal marked-polynomial complete tables. Gate counts for
n=1,...,8 are 1,10,54,150,351,776,1689,3670. The raw record is
`completion_dev.json`. The evaluator and `dag.py` remain unchanged; no
held-out evaluator was accessed. This measured candidate proves (14),
not a polynomial bound.

## Full completion and regular gauge: scope of the numerical experiment

The target for the other experiment is only the fourth paired layer.
At n=10 it has 210 constraints and 190 free skew entries; at n=11 it has
330 constraints and 231 entries. Both xx/yy and all cross entries are
initially free. The target values are explicitly evaluated fourth-order
permanents for this existence test. They are not permitted kernel inputs
in a general compiler, and no such oracle is used in the candidate above.

For k=4 put c=23/4 and K0 with cross block I+c11^T. The differential of
the paired Pfaffian map is

```
L(H)_S=(73/4)*sum_(j in S) H_cross,jj
                 -(23/4)*sum_(j!=l in S) H_cross,jl.           (15)
```

First-order xx and yy directions are invisible. The image is exactly the
span of pair-incidence functions `1_{j,l subset S}`: vertex incidence is
one third of the sum of its incident pair functions. For n>=6 those pair
functions are independent. Indeed compare the sum on T union {a} and
T union {b}, for all three-subsets T outside a,b. Swapping an element of T
forces every difference e_aj-e_bj to be equal, and their three-term sum
forces it to be zero. Symmetry then forces all e_jl equal, and their
six-term sum on S forces them to vanish. Thus the base differential ranks
are exactly 45 and55, far below the number of target coordinates. A naive
application of the implicit function theorem at K0 is not justified.

There is a regular local gauge that avoids most numerical flat directions.
Every 2 by 2 block B_j between the first mode pair and pair j is cJ2 at
the base and hence invertible nearby. With

```
T_j = B_j^(-1) [[0,c],[-det(B_j)/c,0]],  G_j=T_j^T,
```

det(G_j)=1. Congruence by these local G_j preserves every paired
Pfaffian and normalizes that block to the displayed canonical form.
This fixes 3(n-1) parameters regularly at K0: 163 free entries remain at
n=10 and201 at n=11. Generic numerical differential ranks are 160 and198,
with three residual gauge directions. This is a change of coordinates,
not an exclusion of non-affine endpoints. Its 2 by 2 inverses have base
denominator c^2; their jets can be compiled with controlled rational
constants and O(n^2 D^2) scalar overhead through order D.

The regular experiment solves K(t)=K0+tH, with these gauges fixed and every
free H entry bounded by25. It scales the residual by t^4. This bound is
an experimental restriction, not a theorem about all possible sections.
A positive control, starting near a known Gaussian completion, converged
in12 evaluations to residual9.8e-12. Starting far from a known solution
could instead reach a local minimum, so unsuccessful searches cannot
establish non-existence.

## Two exact jets, and why merely solving the linearized equations stalls

Write B=J+tV with four rows, u_j=sum_i V_ij and
q_jl=sum_i V_ij*V_il. For a constructive initial lift choose a cross-only
kernel C(t)=I+c11^T+tD+t^2E, where D is diagonal with

```
d_j=(24/73)*u_j,
E_jj=0,
E_jl=((1+2c)*d_j*d_l-2*(u_j*u_l-q_jl))/(2c), j!=l.             (16)
```

The first target coefficient is 6 sum u_j, which (15) gives from D.
The second target coefficient on each pair is
`2*(u_j*u_l-q_jl)`. The contribution of D squared is
`(1+2c)*d_j*d_l`; (15) applied to E supplies exactly the difference.
Thus (16) matches both jets for every four-column S, using only rational
constants and polynomial expressions in V.

This particular chosen lift is not enough. Let the only nonzero entries
of V be V_1,1=V_2,3=V_3,5=1, and use column7 as a fixed fourth column.
Take the alternating sum over subsets consisting of column7 and one
column from each pair {1,2},{3,4},{5,6}. Every function in the image of L
has zero such third difference. The true third-order coefficient has
contrast1. The contrast predicted by the fixed jets (16) is

```
6*alpha-(2+5c)*alpha^3=342288/389017, alpha=24/73.
```

The residual contrast is therefore 46729/389017. Adding a third jet alone
through L cannot fix this chosen pair of jets. This identifies why a
regular construction must coordinate the earlier invisible directions
with later equations. It does not reject other first/second jets or a
general skew completion; in particular the xx/yy directions and cross
null directions remain available. The exact repeated-row family (10)
already supplies examples of successful nontrivial choices of such jets.

No concrete endpoint-product or 2 by 2 transfer identity that closes the
general fourth layer was obtained in this experiment. Exponentially many
formal endpoint features can have a polynomially computed Gram kernel;
their feature count alone is not a cost obstruction, and no such claim is
used here. A Riccati/Lax notation likewise would still need a constructive
coefficient rule preserving the required layer and the terminal observer.

The remaining requirement is a regular, uniformly constructible fusion
that keeps the number of Gaussian components polynomial as rows continue.
The current implementation gives a controlled exponential decomposition
and full scalar readout, while the full-completion experiment leaves that
stronger requirement open.
